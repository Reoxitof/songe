ICÔNES DE CARACTÉRISTIQUES (STATS) — DOFUS
==========================================

Dépose ici les PNG des icônes de stats du jeu. Le site les utilise
automatiquement s'ils existent ; sinon il retombe sur les icônes SVG
intégrées (donc rien ne casse si un fichier manque).

FORMAT : PNG (idéalement carré, ~32x32 ou plus), fond transparent.

NOMS DE FICHIERS ATTENDUS (exactement ces noms, en minuscules) :

  vitalite.png
  sagesse.png
  pa.png
  pm.png
  portee.png
  initiative.png
  force.png
  intelligence.png
  chance.png
  agilite.png
  puissance.png
  critique.png          (pour "% Critique" / "Coups critiques")
  invocation.png
  prospection.png
  soin.png
  pods.png
  tacle.png
  fuite.png
  retrait-pa.png
  retrait-pm.png
  esquive-pa.png
  esquive-pm.png
  dommage-neutre.png
  dommage-terre.png
  dommage-eau.png
  dommage-feu.png
  dommage-air.png
  resistance-neutre.png
  resistance-terre.png
  resistance-eau.png
  resistance-feu.png
  resistance-air.png

Ces icônes apparaîtront PARTOUT : caractéristiques totales, panoplies,
filtres de recherche, info-bulles d'items, et l'onglet Forgemagie.

Tu peux n'en mettre que quelques-unes : les stats sans fichier gardent
l'icône SVG par défaut.
